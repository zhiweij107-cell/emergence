# 相生 · 五行场

在线作品：[https://zhiweij107-cell.github.io/emergence/](https://zhiweij107-cell.github.io/emergence/)

这是一件涌现主义 WebGL 作品。空间里没有预先建好的世界，只有点、线、面，以及金、木、水、火、土对应的五种柏拉图立体。它们按相生相克的局部规则互相转化；山、河、晶格、火焰都是规则跑出来的，不是画上去的。

现实不走进房间，而是作为气候被吞进去。新闻不出现在屏幕上，只改场的能量流速、相生权重和相克强度。同一套几何，因为当天的世界不同，会长成完全不同的宇宙。

## 和现实世界的关系

场不连接摄像头、麦克风或现场传感器。它和现实的接口只有网络。

外面是新闻，里面是宇宙。观众进场看不到头条滚动、没有字幕墙。他们看到的是：今天这颗几何世界比昨天更干、更碎、更往上烧，或更湿、更往下沉。

事件不直接改颜色、不开关特效。每条头部事件被拆成三个量，注入五行场：

- **这件事在做什么**（破裂 / 流动 / 生长 / 切割 / 固化）→ 扰动哪一行
- **语气**（协议、救援 vs 冲突、灾变）→ 相生还是相克
- **被报道的规模**（是否被多家重复）→ 能量大小

地理坐标只决定种子从空间哪一侧渗入。空间本身是一颗被压扁的地球。

## 每天吃什么数据

每天只吃很少的东西：全球真正的「头部」事件，大约数条。条数少，才像气候；条数一多，就变成信息图。

1. **Wikipedia In the news**（主食）  
   英文维基首页那一小盒，全球编辑共识的当日头部事件。接口公开、免密钥。
2. **BBC World RSS**（调味）  
   不另开一桌菜。只用来看同一事件被重复报道了多少次——重复次数当作强度。
3. 写成一份 `climate.json`  
   渲染端永远只读这份气候文件，不直接碰新闻网站。

流水线：

> 每天定时拉一次 → 收成数条种子 → 写成气候 JSON → WebGL 在场里慢慢消化。

本地更新当天气候：

```bash
npm run fetch-climate
npm run dev
```

## 事件如何变成五行

不要做成「地震就长土、洪水就变蓝」。那是插图。五行按**过程**来认，一条新闻几乎总是混合物。

| 行 | 几何 | 它认什么过程 | 在场里怎么动 |
| --- | --- | --- | --- |
| **金** | 正八面体 | 切割与度量：制裁、军备、边境、金融、法律、天体力学 | 往晶格上靠，高反光 |
| **木** | 正十二面体 | 生长与组织：生态、科学、教育、社会运动 | 往外长，缓慢脉动 |
| **水** | 正二十面体 | 大规模流动：洪水、迁徙、扩散、人道走廊 | 随流场走，半透明 |
| **火** | 正四面体 | 突然断裂：冲突、爆炸、山火、市场暴跌 | 上升、碎裂、加色发光 |
| **土** | 立方体 | 占地与沉淀：地震、选举、领土、机构、死亡 | 沉降、堆叠、固化 |

转化靠两套循环，不是场景切换：

- **相生**：木→火→土→金→水→木。邻居是「我所生」，就分裂、喂能量、改几何。
- **相克**：木克土、土克水、水克火、火克金、金克木。克不是删除，是改结构：剪枝、压扁、结晶、撑裂。
- **过密崩溃**：同类挤在一起会散开或转化。没有它，系统会画满或死寂；有它，才会有灾变和重建。

例如「停火谈判」是金（协议）+ 水（缓和）+ 火（余烬）；「极端高温」是火 + 土（干裂）+ 木（枯萎）。混合物在空间里互相吞噬，这才是涌现。

气候文件里，渲染只认很少几个数：五个能量、一个流动、一个混沌、一组种子。参数一多，就变成仪表盘，不再是涌现。

## 观众会看到什么

打开页面，先是一层介绍，背后的宇宙已经在长。点「进入场」后：

- **黎明**：新种子从边界渗入，先是淡的能量雾，还没有成形。
- **白天**：局部规则开始改写。某片区域相生加快，另一片相克变狠。五种立体在这些气候里自己长、自己碎。
- **显形**：当天最强的头部事件，会留下可辨认但不说明的结构——晶塔、裂谷、林网。感觉「今天不一样」，但读不出新闻标题。
- **沉积**：转化过的位置留下半透明残渣。昨天的火、上周的水还在深处。时间久了，房间里会积一层地质。

左上角细条：淡的是今日气候，实的是场里此刻活着的比例。右上角「关于」可以回到说明。拖动旋转，滚轮推近。

作品仍是宇宙，不是新闻墙。
